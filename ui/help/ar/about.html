حول Inbox Chat

مساعد مجاني مفتوح المصدر لبرنامج Outlook الكلاسيكي. يظهر رقم الإصدار الذي تستخدمه في شريط عنوان نافذة التعليمات.

التقنيات المستخدمة

  • لغة Rust وإطار Tauri لبناء التطبيق، مع WebView2 من Microsoft لعرض النافذة؛
  • SQLite لملف البيانات المحلي؛
  • واجهة الأتمتة في Outlook (COM) لقراءة البريد وحفظ المسودات.

Inbox Chat مشروع مستقل، لا يرتبط بشركات Microsoft أو OpenAI أو Anthropic أو Google أو Moonshot أو Ollama، ولا تعتمده أي منها. أسماء المنتجات ملك لأصحابها.
