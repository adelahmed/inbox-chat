1. اختيار نموذج الذكاء الاصطناعي

افتح Settings واختر مزوّداً من أعلى النافذة. يتذكر التطبيق لكل مزوّد عنوانه ومفتاحه ونموذجه، فيمكنك التنقل بينها.

المزوّدمكان العملالعنوان الافتراضيالنموذج الافتراضي
Ollamaهذا الجهاز أو شبكتكhttp://localhost:11434qwen3:8b
OpenAI ChatGPTسحابيhttps://api.openai.com/v1gpt-5.1
Anthropic Claudeسحابيhttps://api.anthropic.com/v1claude-opus-5-5
Google Geminiسحابيhttps://generativelanguage.googleapis.com/v1beta/openaigemini-2.5-flash
Moonshot Kimiسحابيhttps://api.moonshot.ai/v1kimi-k2-0905-preview
السحابي يعني أن بريدك يغادر شبكتك. مع المزوّد السحابي يرسل التطبيق إلى تلك الشركة الرسائلَ التي يقرؤها المساعد ليجيبك، وكلَّ رسالة تفتحها ما دامت الاقتراحات التلقائية مفعّلة. تعرض نافذة الإعدادات تحذيراً، ويعرض الشريط العلوي شارة cloud. راجع أنظمة جهتك قبل استخدام مزوّد سحابي مع بريد العمل، أما Ollama فيُبقي كل شيء على أجهزتك.

انقر Save عند الانتهاء. يتحول ضوء LLM في الشريط العلوي إلى الأخضر عندما يستجيب النموذج.

2. إعداد Ollama

  1. ثبّت Ollama من ollama.com على هذا الجهاز، أو استخدم خادم Ollama في شبكتك.
  2. نزّل نموذجاً يدعم الأدوات، مثلاً بكتابة الأمر التالي في موجه الأوامر: ollama pull qwen3:8b. تعطي النماذج الأكبر (14B أو 32B) إجابات أفضل إذا كانت ذاكرة جهازك أو خادمك تتسع لها.
  3. في الإعدادات اختر Ollama. أبقِ العنوان http://localhost:11434 لهذا الجهاز، أو اكتب عنوان الخادم، مثل http://gpu-server:11434. ويعيد زر Default العنوان القياسي.
  4. اختر النموذج من القائمة واحفظ.

3. استخدام مزوّد سحابي

  1. أنشئ مفتاح API من لوحة المطورين لدى المزوّد: OpenAI أو Anthropic أو Google AI Studio أو Moonshot. وقد يترتب على الاستخدام رسوم.
  2. في الإعدادات اختر المزوّد، والصق المفتاح في API key.
  3. اختر النموذج واحفظ.
مفتاحك محمي. يحفظه التطبيق مشفّراً بآلية Windows لحساب المستخدم الخاص بك، ولا يعرضه في النافذة مرة أخرى سوى أحرفه الأخيرة، ولا يرسله إلا إلى ذلك المزوّد. ويحذفه زر Remove.

4. قائمة النماذج والوسيط والخيارات

الحقلوظيفته
Model
النموذج		يعرض النماذج التي يتيحها الخادم، ويعيد ⟳ Refresh تحميل القائمة. وفي Ollama يعرض حجم كل نموذج وهل يدعم الأدوات. اختر نموذجاً يدعم الأدوات، فالمساعد يحتاجها للبحث في بريدك وقراءته. وإذا تعذّر تحميل القائمة يمكنك كتابة اسم النموذج.
Proxy
الخادم الوسيط		في شبكات الشركات يمر الاتصال بالإنترنت غالباً عبر خادم وسيط. فعّل Use proxy لاستخدام إعدادات Windows، أو اكتب عنواناً مثل http://proxy:8080، وهذا ضروري إذا كان Windows يستخدم نص إعداد تلقائي للوسيط. يستخدم المزوّدون السحابيون الوسيط افتراضياً، بخلاف Ollama داخل شبكتك.
Context window
نافذة السياق
(Ollama فقط)		مقدار النص الذي يستطيع النموذج النظر فيه دفعة واحدة (الافتراضي 16384). تتيح القيم الأكبر قراءة مراسلات أطول، لكنها تحتاج إلى ذاكرة ووقت أكثر.
Reasoning
التفكير
(Ollama فقط)		للنماذج التي «تفكر» قبل الإجابة: Off أسرع، وOn قد يكون أدق، وModel default يترك القرار للنموذج.
Temperature
درجة العشوائية		القيم الأقل أكثر دقة وثباتاً، وتناسب القيمة 0.2 أعمال البريد. تستخدم نماذج Claude ونماذج GPT-5 وسلسلة o من OpenAI إعدادها الثابت الخاص.
Your name
اسمك		ليكتب المساعد من منظورك.

5. الملف الشخصي: معلومات عنك

من خلال Profile → About me & department تعرّف التطبيق بنفسك، فيميّز ما يخصك ويفهم عملك.

الحقلالاستخدام
How you appear in To/CCأسماء العرض وعناوينك، واحد في كل سطر. يكتشف التطبيق حساب Outlook الخاص بك تلقائياً، وأضف غيره إن وجد: عنواناً قديماً، أو صندوقاً مشتركاً ترد نيابة عنه.
Ways people mention youكيف يخاطبك الناس في نص الرسائل، مثل «د. سامي» أو “Dr. Sam”. ويمنح ذلك شارة Mentions you.
Job title، Departmentالمسمى الوظيفي والإدارة: سياق مختصر للمساعد.
Department keywordsالموضوعات وأسماء المشروعات والمنتجات، واحدة في كل سطر. تحصل الرسائل التي تتضمن إحداها على شارة Department. ويطابق التطبيق صيغ الكتابة العربية المختلفة.
Department mailing listsعناوين الفريق، مثل team@example.com، ويميّز التطبيق البريد الموجه إليها أيضاً.
Backgroundفقرة عن عمل فريقك ومشروعاته وشركائه وطلباته المعتادة، يقرؤها المساعد مع كل طلب. احرص على خلوّها من البيانات الشخصية أو السرية.

6. الملف الشخصي: أسلوب الكتابة

تتحكم Profile → Writing style في شكل المسودات. ويطبّق التطبيق الأسلوب بنفسه، فتأتي كل مسودة متسقة أياً كان ما يكتبه النموذج.

الحقلمثالملاحظات
LanguageArabicلغة الملخصات والاقتراحات والمسودات. اتركه فارغاً ليجيب التطبيق بلغة كل رسالة.
Apply my style☑يفعّل القواعد أدناه. وعند إيقافه تتضمن المسودات النص فقط.
Greeting, one recipient«مع التحية والتقدير ل{name}»يضع التطبيق مكان {name} طريقة مخاطبتك للشخص، مما تعلّمه من رسائلك السابقة، أو اسمه الأول.
Greeting, several«مع التحية والتقدير للجميع»عندما يكون في سطر «إلى» شخصان أو أكثر.
Special people«خالد منصور|Khalid Mansour = مع التحية والتقدير لسعادة الرئيس التنفيذي» واحد في كل سطر: أسماء الشخص وصيغ كتابتها مفصولة بالرمز |، ثم = والتحية. يستخدمها التطبيق عندما يكون ذلك الشخص وحده في سطر «إلى».
Sign-off«مع تحياتي
-سامي»		عبارة الختام، ويمكن أن تمتد على عدة أسطر.
Font، Right-to-leftSakkal Majalla 14خط نصك في المسودة وحجمه واتجاهه. للعربية اختر خطاً عربياً وفعّل Right-to-left.

تتصل التحية العربية بالاسم اتصالاً صحيحاً: ل + الأستاذ خالد ← للأستاذ خالد. وتعرض المعاينة أسفل الحقول النتيجة قبل الحفظ.

تكتب بالإنجليزية؟ استخدم مثلاً Dear {name}, وDear all, وBest regards مع خط مثل Calibri، دون تفعيل Right-to-left.

7. الملف الشخصي: التعلّم والسلوك

الخيارالافتراضيوظيفته
Mark emails as read…مفعّليضع علامة «مقروءة» على الرسالة في Outlook عند فتحها، أو عندما يعالجها المساعد.
Learn from my sent repliesمفعّليقرأ العناصر المرسلة ليتعلّم ردودك وجهات اتصالك، ويحفظها على هذا الجهاز فقط.
Show the summary & suggested reply automatically…مفعّليملأ لوحة ✨ عند فتح الرسالة. وعند إيقافه ينتظر نقرك.
Look back365 يوماًالمدة التي يرجع إليها التطبيق في العناصر المرسلة للتعلّم.

يبدأ Learn now جولة تعلّم فوراً، ويحذف Forget learned replies ما تعلّمه التطبيق ولوحات ✨ المحفوظة، دون أي أثر على رسائلك.

8. ملفات الإعدادات (استيراد / تصدير)

يحفظ قسم Settings → Import / export إعدادات الذكاء الاصطناعي وملفك الشخصي (الإدارة، والكلمات المفتاحية، واللغة، وأسلوب الكتابة، وخيارات التعلّم) في ملف واحد، ويحمّل مثل هذا الملف على جهاز آخر أو لشخص آخر. استخدمه في:

  • نقل إعدادك إلى حاسب جديد؛
  • تزويد الفريق بنقطة بداية واحدة (عنوان الخادم، والنموذج، ونبذة الإدارة)، ثم يضيف كل شخص اسمه وأسلوبه؛
  • الاحتفاظ بنسخة من إعداداتك.

لا يتضمن الملف مفاتيح API إلا إذا حددت Include API keys، وعندها يكتبها التطبيق نصاً مقروءاً، فاحرص على سرية الملف. ولا يصدّر التطبيق أبداً الردود المتعلَّمة ولا المحادثات. ويفحص الملف كاملاً قبل حفظ أي شيء، فلا يغيّر الملف التالف شيئاً. وعند التثبيت الجديد تعرض نافذة الترحيب استيراد ملف مباشرة.

{
  "format": "inbox-chat-settings",
  "version": 1,
  "llm": { "provider": "ollama", "temperature": 0.2, "num_ctx": 16384,
           "providers": { "ollama": { "url": "http://gpu-server:11434", "model": "qwen3:14b", "use_proxy": false } } },
  "profile": { "dept_name": "Customer Experience", "language": "English",
               "style": { "enabled": true, "greeting_single": "Dear {name},", "greeting_multi": "Dear all,",
                          "signoff": "Best regards\nSam", "font_family": "Calibri", "font_size_pt": 11, "rtl": false } }
}

يمكن الاستغناء عن أي من الجزأين، وتبقى الحقول غير الموجودة في الملف على قيمها الحالية.

9. متقدم: خيارات التشغيل

للمسؤولين والمستخدمين المتقدمين. تحدد متغيرات البيئة القيم الابتدائية، وتتقدم عليها القيم المحفوظة في الإعدادات.

الخيارالأثر
--demo أو INBOX_CHAT_DEMO=1صندوق بريد تجريبي؛ لا يتعامل التطبيق مع Outlook ولا يحفظ شيئاً.
INBOX_CHAT_DBالمسار الكامل لملف البيانات بدلاً من الملف القياسي (راجع البيانات والخصوصية).
INBOX_CHAT_PROVIDERإحدى القيم: ollama أو openai أو anthropic أو gemini أو kimi.
OLLAMA_URL، OLLAMA_MODELعنوان خادم Ollama والنموذج.
OLLAMA_NUM_CTX، OLLAMA_THINK، OLLAMA_USE_PROXYنافذة السياق، والتفكير (true/false)، واستخدام الوسيط (true/false).
OPENAI_API_KEY، ANTHROPIC_API_KEY،
GEMINI_API_KEY، MOONSHOT_API_KEY		مفاتيح API، إن كنت تفضّل عدم حفظها في التطبيق.
INBOX_CHAT_USERاسمك، كما في الإعدادات.
INBOX_CHAT_CA_BUNDLEملف PEM يحتوي الشهادة الجذرية لجهتك، للشبكات التي تفحص الاتصالات الآمنة.
