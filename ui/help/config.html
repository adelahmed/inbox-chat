Configuration guide

Two windows hold all the options: Settings for the AI model, and Profile for who you are and how you write. Changes apply to your next request; there is no need to restart.

1. Choosing the AI model

Open Settings and pick a provider at the top. Each one remembers its own address, key and model, so you can switch back and forth.

Cloud means your mail leaves your network. With a cloud provider, the emails the assistant reads to answer you, and each email you open while automatic suggestions are on, are sent to that company. Settings shows a warning and the top bar a cloud badge. Check your organisation's rules before using a cloud provider with work mail. Ollama keeps everything on your own computers.

Click Save when done. The LLM light in the top bar turns green when the model answers.

2. Setting up Ollama

  1. Install Ollama from ollama.com on this PC, or use an Ollama server on your network.
  2. Download a model that can use tools, for example in a command prompt: ollama pull qwen3:8b. Larger models (14B, 32B) give better answers if your PC or server has the memory for them.
  3. In Settings, choose Ollama. Keep http://localhost:11434 for this PC, or type the server's address, e.g. http://gpu-server:11434. Default restores the standard address.
  4. Pick the model from the list and save.

3. Using a cloud provider

  1. Create an API key in the provider's developer console (OpenAI, Anthropic, Google AI Studio or Moonshot). Paid usage may apply.
  2. In Settings, choose the provider and paste the key into API key.
  3. Choose a model and save.
Your key is protected. It is stored encrypted with Windows for your user account, is never shown again in the window (only its last characters), and is sent only to that provider. Remove deletes it.

Profile → About me & department tells the app who you are, so it can mark what concerns you and understand your work.

Job title, DepartmentShort context for the assistant.

8. Settings files (import / export)

Settings → Import / export saves the AI settings and your Profile (department, keywords, language, writing style, learning options) as one file, and loads such a file on another PC or for another person. Use it to:

  • move your setup to a new computer;
  • give a team one starting point (server address, model, department background); each person then adds their own name and style;
  • keep a copy of your configuration.

API keys are left out unless you tick Include API keys; they are then written in plain text, so keep such a file private. Learned replies and conversations are never exported. A file is checked completely before anything is saved, so a damaged file changes nothing. On a new installation, the welcome window offers to import a file straight away.

{
  "format": "inbox-chat-settings",
  "version": 1,
  "llm": { "provider": "ollama", "temperature": 0.2, "num_ctx": 16384,
           "providers": { "ollama": { "url": "http://gpu-server:11434", "model": "qwen3:14b", "use_proxy": false } } },
  "profile": { "dept_name": "Customer Experience", "language": "English",
               "style": { "enabled": true, "greeting_single": "Dear {name},", "greeting_multi": "Dear all,",
                          "signoff": "Best regards\nSam", "font_family": "Calibri", "font_size_pt": 11, "rtl": false } }
}

Either part may be left out; missing fields keep their current values.
