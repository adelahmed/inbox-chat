About Inbox Chat

A free, open-source assistant for classic Outlook. The version you are running is shown in the title bar of this Help window.

Questions, ideas and bug reports are welcome. When reporting a problem, include the version number and what you did, but no email content or API keys.

Built with

  • Rust and Tauri for the app, with Microsoft WebView2 for the window;
  • SQLite for the local data file;
  • Outlook's automation interface (COM) to read mail and save drafts.
