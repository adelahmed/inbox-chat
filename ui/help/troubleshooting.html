Troubleshooting

The two lights in the top bar tell you where a problem is: Outlook for your mailbox, LLM for the AI model.

Outlook

The Outlook light is red or no folders appear

  • If Outlook was closed, the app starts it minimized and connects once it has loaded. This can take up to a minute and a half.
  • Finish any Outlook window that is waiting for you (profile choice, password, update), then click ⟳ next to Folders.
  • Make sure you use classic Outlook. If the New Outlook switch at the top of Outlook is on, turn it off. The new Outlook cannot be used by other programs.

Outlook asks “A program is trying to access e-mail address information…”

This is Outlook's own security guard. Whether it appears depends on your organisation's settings and antivirus status. Choose Allow (for up to 10 minutes) to let Inbox Chat read your mail, or ask your IT team to approve the app.

Some pictures are missing in an email

Pictures stored on the internet are not downloaded, on purpose. Click Open in Outlook to see the email with them.

AI model

The LLM light is red

  • Ollama: check that Ollama is running on that computer, that the address in Settings is right (default http://localhost:11434) and that the model is downloaded (ollama list). Another PC's Ollama must be set up to accept connections from the network.
  • Cloud provider: check the API key and that your account has credit. On a company network, tick Use proxy; if Windows uses an automatic proxy script, type the proxy address yourself.
  • Certificate (TLS) errors on a company network that inspects secure connections: set INBOX_CHAT_CA_BUNDLE to your company's root certificate (PEM file). See start options.

“Could not decrypt the … API key”

The data file was copied from another PC or Windows account, where the key was encrypted. Enter the key again in Settings and save.

The assistant doesn't look at my mail, or invents answers

Choose a model that can use tools (the Model list shows this for Ollama). Very small models struggle; try a larger one.

Answers are slow

  • Local models depend on your hardware. Try a smaller model, set Reasoning to Off, or lower the Context window.
  • The ✨ panel runs for each email you open. If that slows you down, turn off automatic suggestions in Profile → Learning & behaviour.

Drafts and recipients

I can't find a draft

Drafts are saved in Outlook's Drafts folder (click it in the folder tree), newest first. The chat shows each saved draft as a step.

The assistant asks which person I mean

Several people match the name you gave. Answer with the full name or the email address. Names are learned from your Sent Items; Profile → Learning & behaviour → Learn now picks up people you wrote to recently.

My Outlook signature is missing in drafts

Outlook adds signatures only in its own editor. Put your sign-off in Profile → Writing style; it is added to every draft.

The greeting or sign-off appears twice, or not at all

Check Apply my style in Profile. With it on, the app removes greetings the model wrote and adds yours; with it off, the draft is the model's text as written.

The app

A yellow banner says “Could not open … Nothing will be saved”

The data file is in use or its folder can't be written. Close other copies of Inbox Chat and start it again. See where your data is kept.

Windows SmartScreen warns when starting the app

The app isn't code-signed. Click More info → Run anyway. Download it only from the project's official release page, github.com/adelahmed/inbox-chat/releases; each release lists the file's SHA-256 checksum.

I want to start over

See Starting fresh: rename the data file instead of deleting it.
