Data & privacy

1. Where your data is kept

Everything Inbox Chat saves is in one database file (SQLite) in your Windows user profile:

Data file %APPDATA%\InboxChat\inbox-chat.db
which is usually C:\Users\your-user-name\AppData\Roaming\InboxChat\inbox-chat.db

The exact path on this PC is shown at the bottom of this Help window, with a Copy path button. To open the folder: press Win+R, type %APPDATA%\InboxChat and press Enter.

While the app is running you will also see inbox-chat.db-wal and inbox-chat.db-shm next to it. They are part of the database; leave them alone.

Please don't delete this file. It holds your settings, encrypted API keys, profile and writing style, conversations and everything the app has learned. Without it the app starts as if newly installed: the welcome window appears, API keys and your profile must be entered again, and learning starts over from your Sent Items. Disk-cleaning tools usually leave AppData\Roaming alone, but check before you clean it by hand. Your emails and drafts are not in this file; they stay in Outlook.

The file is created automatically the first time the app runs. Each Windows user on the PC has their own.

Because the file contains text from your emails, treat it like your mailbox: don't share it and keep backups in a safe place.

3. Back up and restore

  1. Close Inbox Chat, so the database is complete in one file.
  2. Copy inbox-chat.db from %APPDATA%\InboxChat to your backup location.
  3. To restore, close the app and copy the file back to the same place (replace the existing one).
Only need your setup? Settings → Export to file… saves settings and profile as a small file that you can import anywhere. See Settings files.

4. New PC or another location

  • New PC or Windows account: the easiest way is Settings → Export on the old PC and Import on the new one. If you copy the data file instead, enter your API keys again: they were encrypted for the old account. Learned replies rebuild themselves from Sent Items either way.
  • Another folder: set the environment variable INBOX_CHAT_DB to the full path of the file you want, for example in a command prompt: setx INBOX_CHAT_DB "D:\InboxChat\inbox-chat.db", then restart the app. To keep your data, close the app and move the existing file there first.
  • Keep the file on a local disk. A folder that a cloud-storage app keeps in sync can damage a database that is open.

5. Temporary files

Attachments you preview or open are saved to %TEMP%\InboxChat\attachments, and pictures inside emails to %TEMP%\InboxChat\inline. These are copies; you can delete them whenever the app is closed.

6. What leaves your PC

Inbox Chat talks to one outside party only: the AI provider you chose in Settings. It sends:

  • your question and the emails the assistant reads to answer it (senders, recipients, subjects, text);
  • each email you open, when automatic ✨ suggestions are on;
  • your profile's department, keywords and background, and a few of your past replies as style examples.

Nothing else is sent anywhere: no usage data, no tracking, no update checks.

Keep everything in-house. With Ollama on this PC or on your own network, your mail never leaves your organisation.
With a cloud provider, mail content is processed by that company under its terms. Check your organisation's data policy first; the top bar shows a cloud badge whenever a cloud provider is selected.

8. Built-in protection

  • Emails are shown in a locked-down view: scripts inside an email never run.
  • Pictures stored on the internet are not downloaded, so senders can't tell when you read their email.
  • Links ask before opening in your browser.
  • Risky attachment types (programs, scripts) are refused, like in Outlook.
  • Attachments you open are marked as downloaded from the internet, so Office opens them in Protected View.
  • API keys never appear in the window after you save them.

9. Starting fresh

To reset the app completely, close it and rename inbox-chat.db (for example to inbox-chat-old.db) rather than deleting it, so you can go back. The next start creates a new, empty file and shows the welcome window. To clear only part of the data, use Forget learned replies in Profile or delete conversations with 🗑.
